## Installation and Execution

Requires Python 3.8 or higher with standard library only.

```bash
git clone https://github.com/TAVARDT-USA/hacked-site-seo-spam-detector-us.git
cd hacked-site-seo-spam-detector-us
python seo_spam_detector.py example.com
```

To run in automated pipelines with JSON output:

```bash
python seo_spam_detector.py example.com -json
```
